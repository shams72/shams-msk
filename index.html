SerpentBot 🔗

SerpentBot is a snake game that utilizes a Breadth-First Search (BFS) algorithm enhanced with the Manhattan distance heuristic to efficiently locate the nearest prey without crossing its own body. If no valid moves remain, it halts to avoid collision. The game features both auto mode, where BFS and heuristics are used, and manual mode, where the snake can be controlled using the arrow keys.

Tech Stack: React, Breadth-First Search, Manhattan distance
